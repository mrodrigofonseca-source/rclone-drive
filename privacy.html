Política de privacidad

Google Drive 2 TB Rclone es una aplicación de uso personal.

Utiliza la API de Google Drive para consultar, copiar, crear, modificar y eliminar archivos por indicación del usuario.

Los datos se gestionan desde el ordenador del usuario. Las credenciales OAuth se almacenan localmente.

Los datos no se venden ni se utilizan con fines publicitarios.

El usuario puede eliminar sus datos y revocar la autorización desde su cuenta de Google.

El tratamiento de datos está sujeto a la política de datos de usuario de las API de Google, incluidos los requisitos de uso limitado.
